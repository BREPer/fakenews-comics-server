# 项目结构

一句话：**`app/server-go` 是后端（唯一进程），`app/web` 是前端（构建后由后端当静态文件伺服）**，
其余目录都是打包与开发配套。

## 顶层

```
fakenews-comics/
├── manifest              fpk 身份信息（应用 ID / 版本 / 端口），**版本号的单一真源**
├── ICON.PNG             应用中心图标（256 那张见 ICON_256.PNG，由 tools/gen_icons.py 生成）
├── cmd/                 9 个生命周期脚本（安装/升级/卸载的 init 与 callback，fpk 与 fnOS 的契约）
├── config/
│   ├── privilege        包用户声明（docker-fakenews-comics）
│   └── resource         docker-project 声明（指向 app/docker）
├── wizard/
│   ├── install          安装向导：收集 APP_PORT 与 COMIC_ROOT
│   └── uninstall        卸载向导：保留或删除数据
├── app/                 应用本体（见下）
├── tools/               开发期脚本：回归、造数据、出图、性能（见 tools/README.md）
├── docs/                设计与专题文档（实现方案、项目结构、各功能取舍记录）
├── build.ps1 / build.sh fpk 打包助手（构建前端 → 交叉编译 → staging → fnpack）
├── dev.ps1 / dev.sh     本地一键开发（编后端 + 起 vite）
├── README.md            上手、约定、API 一览
├── CONTRIBUTING.md      开发环境、提交前检查、代码约定
└── LICENSE              GPL-3.0
```

## app/ —— 三块

```
app/
├── docker/docker-compose.yaml   单容器编排（build context = ../server-go，装到 NAS 后现场构建）
├── ui/                          fnOS 桌面入口（config 声明 type:url + 各尺寸图标）
├── server-go/                   后端（Go，唯一进程）
└── web/                         前端（Vite + React + TS）
```

### 后端 `app/server-go/`

```
server-go/
├── main.go              装配：路由 + 静态伺服 + SPA fallback + -healthcheck 自检
├── go.mod / go.sum
├── Dockerfile           FROM scratch，只 COPY 二进制与前端 dist
├── goenv.sh             可选：go 不在 PATH 时导出工具链/代理环境（被 source，不直接执行）
├── third_party/         vendored 的 PDFium WASM 绑定（MIT）与 rardecode
└── internal/
    ├── auth/            单账号门禁：登录、会话 Cookie、限流
    ├── db/              modernc sqlite（WAL / 语句缓存）+ schema.sql
    ├── env/             环境变量解析（APP_PORT / COMIC_ROOT / DATA_DIR / WEB_DIST …）
    ├── gate/            解码与光栅化的全局闸（限并发、大图独占、内存归还）
    ├── httputil/        错误信封、参数校验、分页工具
    ├── images/          缩放（x/image）+ 磁盘缓存 + 内存 LRU + 原图 Range 流
    ├── lib/             facets 缓存等零散工具
    ├── logger/          slog 封装
    ├── routes/          REST 路由（comics / pages / progress / favorites / scan / libraries /
    │                    settings / cache / backup / upload）
    ├── scanner/         增量扫描：walker / 命名解析 / 章节模型 / 调度
    ├── sources/         源抽象：folder / zip(含 cbz、epub spine) / pdf(WASM PDFium) / rar
    └── version/         版本号（打包时 -ldflags 注入）
```

### 前端 `app/web/`

```
web/
├── vite.config.ts       dev 时把 /api 代理到 127.0.0.1:13800
├── tailwind.config.js
└── src/
    ├── main.tsx / App.tsx     入口与路由表
    ├── theme.ts               ink 色阶 + dark 类切换
    ├── index.css              CSS 变量与动画关键帧
    ├── api/
    │   ├── client.ts          fetch 封装（信封解包 / 错误码 / 重试）
    │   └── queries.ts         queryKeys + useComics/useComic/… + LIST_PAGE_SIZE
    ├── components/
    │   ├── layout/            AppShell / SideNav / BottomTabs / ScrollManager / BootShell
    │   ├── comic/             ComicCard 等卡片与网格
    │   ├── library/           库管理：列表、表单、上传
    │   ├── reader/            ReaderShell / pagers（四种翻页）/ useProgressSync / usePinchZoom
    │   ├── auth/              RequireAuth
    │   └── ui/                Button / Chip / Sheet / ConfirmDialog / Toast / Skeleton
    ├── pages/                 Home / Search / Detail / Shelf / Libraries / Settings / Reader / Login
    ├── hooks/                 useMediaQuery / useWakeLock
    ├── utils/                 devicePrefs / readerPrefs（localStorage 偏好）/ pagerMode / nav
    └── types/                 前后端共享契约（TS interface）
```

## 按任务找文件

| 想改什么 | 去哪儿 |
|---|---|
| 加一个接口 | `internal/routes/`（挂载在 `main.go`），类型同步 `web/src/types/` |
| 支持一种新格式 | `internal/sources/`（实现 source 接口即可，扫描与阅读都不用改） |
| 扫描规则 / 章节切分 | `internal/scanner/`（`naming.go` 管命名解析） |
| 缩略图与画质 | `internal/images/` + `internal/gate/`（并发与内存上限） |
| 翻页动效 | `web/src/components/reader/pagers.tsx`、`pan-track.ts` |
| 阅读进度上报 | `web/src/components/reader/useProgressSync.ts` |
| 设备偏好（按设备存） | `web/src/utils/devicePrefs.ts`、`readerPrefs.ts` |
| 主题色 / 视觉 | `web/src/theme.ts` + `index.css` |
| 打包与版本 | `manifest`（版本单一真源）+ `build.ps1` / `build.sh` |
| 测试与造数据 | `tools/`（先看 `tools/README.md`） |

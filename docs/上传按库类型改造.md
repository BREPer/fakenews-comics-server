# 上传按库类型改造：章节型「上传整部漫画」解压入库（2026-10-23）

上传入口原来对两类漫画库一视同仁：压缩包和图片文件夹都收，全部原样落到库根。
本章起按库类型分流，行为由用户明确要求定义：

| 库类型 | 入口文案 | 接受格式 | 落盘行为 |
|---|---|---|---|
| 章节型（chapter） | **上传整部漫画** | 仅压缩包：`.cbz/.zip/.tar/.cbt/.rar/.cbr` | 创建以压缩包名称命名的文件夹，**自动解压进去**；压缩包本体不保留 |
| 单篇型（single） | 上传漫画 | 压缩包 + `.epub/.pdf`（另收 `.7z/.cb7`，可上传但暂不支持阅读） | **原样落盘，不解压** |

一部漫画一个包：多卷用户请先把各卷打成一个包再传（包内一级目录/子目录即分章，
与 NAS 目录的既有识别规则一致）。

## 一、为什么章节型要解压而不是留包

留包有两个问题：
1. **双层嵌套**：`库根/海贼王.cbz` 在章节型里会被扫描器当成「一部漫画=一个包」，
   包内一级目录当分章——能用，但用户在文件管理器里看到的是包，不是可浏览的目录；
2. **散图+包同目录会算重章**：若解压后的图片和原包留在同一文件夹，扫描器会把
   顶层散图和顶层压缩包各算一章，同一批页出现两次。

所以章节型的正确形态就是「一个漫画一个文件夹」，这也是上传文案叫「上传整部漫画」的原因。

## 二、服务端实现（Go，`internal/routes/upload.go` + `upload_extract.go`）

流程：multipart → 按 `libraries.type` 分流 → 章节型落临时文件 → 解压 → 就位 → 触发扫描。

**解压的关键决策：**

1. **先解到点号临时目录，成功后才就位**（`.fnx-*`，扫描器跳过点号项）。
   坏包/空包直接报错进 `skipped`，库根不留半截文件夹。
2. **单根目录上提**（`liftSingleRootDir`）：整个包只打了一个顶层文件夹时
   （一键打包的常见形态），内容上提一层，避免 `海贼王/海贼王/第01卷` 双层嵌套。
3. **重复上传=替换**：目标文件夹已存在时，旧目录退到点号备份位、新的就位后再删，
   就位失败自动回滚——旧漫画不会丢，旧版本的残留页也不会留。
4. **条目净化与跳过**：拒绝 `..` 穿越；隐藏目录 / `__MACOSX` / `@eaDir` / 样张
   （sample/preview/thumbnail）按扫描器同规则跳过；zip/tar 的软链条目不落盘。
5. **上限**：单条目 2GB、单包解压总量 8GB。图片再压缩率接近 1:1，2GB 的包正常
   解出来约 2GB，能到 8GB 的只有 zip bomb。
6. **rar 跳过的条目必须 drain**：固实归档跳过文件头不解压会丢字典（与
   `sources/rar.go` 读取侧同一约束）；解压是顺序全读，天然兼容固实包。

**响应契约**：形状不变（`written/bytes/skipped/libraryId/scanning`），
新增 `folders`（章节型本次上传新建并解压入库的文件夹名列表）。前端按类型展示结果页。

## 三、前端（`components/library/UploadSheet.tsx`）

- 章节型：单个「上传整部漫画」按钮，accept 仅压缩包；文案说明「自动建文件夹并解压」；
  结果页列出新建的漫画文件夹。
- 单篇型：「上传漫画」按钮，accept 压缩包 + epub/pdf；文案说明「原样上传、不解压」。
- 两类都去掉了「选择文件夹」入口（上传 only 文件）；客户端按扩展名预过滤，
  不合法的文件在确认前就以黄色提示列出，不会白传一趟。
- 库卡片的上传按钮 tooltip 也按类型区分（上传整部漫画 / 上传漫画）。

  zip/tar/rar 解压、单根目录上提、隐藏/样张/软链跳过、穿越防护、空包/坏包报错、
  重复上传替换（含备份清理）、文件夹名净化（非法字符/前导点/限长/空名回落）。
  rar 用例复用了 sources 包同款「最小 RAR3 store 生成器」，并显式验证
  「跳过样张后 drain，后续条目内容不损坏」。

    压缩包不残留、自动入库且页数=24（12 章×2 页）；
  - E4b 单根目录包 → 上提后 `整包测试/第01卷/001.png` 在、`整包测试/整包测试` 不在；
  - E4c 单篇型 → written=1、包原样落库根、不建文件夹；
  - E4d 章节型传 epub → written=0 且进 skipped；
  - 只读库 403 反证保留。
- `tools/journey_test.mjs` 上传段按新契约重写（按库类型分支，夹具改由
  `tools/make_upload_fixture.py` 现场生成，不再依赖外部预置目录）。
- Go 黑盒回归 567/567 不变（上传不在回归契约内，属新增行为）。

## 五、遗留
